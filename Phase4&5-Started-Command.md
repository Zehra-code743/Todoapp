# Phase 4 & 5: Started & Deployment Commands

This document provides a comprehensive guide for the **Citizen Reporting & Transparency Platform**'s Phase 4 (Cloud-Native) and Phase 5 (Advanced Features) deployment and local development.

---

## 🚀 Project Overview: Citizen Reporting & Transparency Platform

The project has evolved from a simple Todo application into a full-scale **Citizen Reporting & Transparency Platform**. This platform empowers citizens to report civic issues, track their progress, and view public transparency dashboards. Admins manage the lifecycle of these reports through a dedicated dashboard.

### Core Features:
- **Citizen Portal**: Reporting gateway and ticket tracking.
- **Admin Dashboard**: Department management, issue resolution, and user oversight.
- **Transparency Dashboard**: Public analytics and map-based visualizations.
- **Microservices Architecture**: Specialized services for Tasks, Chat, Notifications, and Recurring events.

## 🛠️ Step-by-Step Execution Guide

### 1. Local Development (No Containers)

Run the frontend and backend separately for rapid development.

**Backend (FastAPI):**
```bash
cd backend
# Activate virtual environment
# Windows: venv\Scripts\activate | Unix: source venv/bin/activate
uvicorn src.main:app --reload --port 8000
```

**Frontend (Next.js):**
```bash
cd frontend
npm install
npm run dev
```
*Access at: http://localhost:3000*

---

### 2. Containerization (Docker)

To run the entire stack as containers:

**Build Images:**
```bash
# Build Frontend
docker build -t citizen-frontend:latest ./frontend

# Build Backend
docker build -t citizen-backend:latest ./backend
```

**Run Locally:**
```bash
docker-compose up -d
```

---

### 3. Kubernetes Deployment (Minikube)

For production-grade testing using Kubernetes.

**Step 1: Start Minikube & Load Images**
```bash
minikube start
minikube image load citizen-frontend:latest
minikube image load citizen-backend:latest
```

**Step 2: Initialize Infrastructure (Kafka & PostgreSQL)**
```bash
kubectl apply -f k8s/namespace.yaml
kubectl apply -f k8s/postgresql.yaml
kubectl apply -f k8s/kafka/
```

**Step 3: Deploy Core Services**
```bash
kubectl apply -f k8s/deployments/
kubectl apply -f k8s/services/
```

**Step 4: Verify Deployment**
```bash
kubectl get pods -n default
kubectl get svc -n default
```

**Step 5: Access the Application**
```bash
minikube service frontend-service --url
```

---

### 4. Advanced Commands (Phase 5)

**Dapr Integration:**
Run services with Dapr sidecars for event-driven communication (Kafka).
```bash
dapr run --app-id backend --app-port 8000 -- uvicorn src.main:app
```

**Helm Deployment:**
```bash
helm install citizen-platform ./helm/todo-chart
```

**Monitoring & Logs:**
```bash
kubectl logs -l app=citizen-backend -f
```
