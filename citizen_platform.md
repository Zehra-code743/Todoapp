# Citizen Reporting & Transparency Platform - Project Plan

## Project Goal
A complete Next.js + Tailwind web platform where citizens report civic issues, track status, and view public dashboards. Admins manage issues, departments, users, and analytics. Backend is in Python FastAPI.

## Architecture
- **Citizen Portal**: User-facing issue reporting and tracking.
- **Admin Dashboard**: Internal management for issues and departments.
- **Transparency Dashboard**: Public view for analytics and maps.
- **Backend (FastAPI)**: Central API for data, auth, and analytics.

## Folder Structure (Initialized)
- `/citizen`: Citizen portal frontend components.
- `/admin`: Admin dashboard frontend components.
- `/reporting`: Public transparency frontend components.
- `/analytics`: Analytics modules.
- `/dashboard`: Shared dashboard components.
- `/backend`: FastAPI backend services and models.
